Privacy Policy

Last updated: 21 October 2026

1. About This Application

Telegram Calendar Bot is a personal application that allows its authorized user to create Google Calendar appointments through Telegram.

2. Information Accessed

The application processes Telegram messages containing appointment details, such as event titles, dates, times, and durations.

With the user's authorization, the application accesses Google Calendar to create events.

3. How Information Is Used

Information is used to interpret appointment requests, create Google Calendar events, and send confirmations through Telegram.

4. Data Sharing

Appointment information is transmitted to Google Calendar to create requested events and to Telegram to provide confirmations. The application does not sell personal information.

5. Data Storage and Security

The application uses authentication credentials to access Google Calendar. Access is restricted to the authorized Telegram user. Credentials are intended to be stored securely using Google Cloud services.

6. Data Retention

Calendar events remain in Google Calendar until removed by the user. The hosting provider may retain operational logs according to its settings.

7. User Control

The user can manage or delete calendar events through Google Calendar and revoke application access through their Google Account security settings.

8. Contact

For privacy inquiries, contact the application developer using the support email provided on the Google OAuth consent screen.
